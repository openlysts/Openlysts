# Contributing to Openlysts

Thank you for your interest in Openlysts! We appreciate every kind of
contribution — even though Openlysts is a closed-source product, your
feedback, ideas, and reports genuinely shape what we build.

## What this means for you

Openlysts is a **closed-source product**: only the hosted web
application is publicly available. The source code in this repository
is proprietary (see [LICENSE](LICENSE)) and is **not** open for
contributions, forks, local builds, or self-hosting.

That doesn't mean you can't help. Here's how:

## Ways to contribute

1. **Use the app and tell us what breaks or confuses you** — every
   bug report starts as a conversation.
2. **Suggest features** — we read every idea, and the roadmap is
   built from real user needs.
3. **Report security issues** — responsibly. See
   [SECURITY.md](SECURITY.md) for our disclosure process.
4. **Share the app** — word of mouth is the biggest help a solo
   creator can get.
5. **Sponsor the project** — see the Sponsor link in the README.
   Running Openlysts has real costs (databases, APIs, hosting), and
   support from users like you keeps it free for everyone.

## Reporting bugs

Before reporting, please:

- Search existing issues to avoid duplicates.
- Include the page/feature where it happened, what you expected, and
  what you saw (screenshots help a lot).
- Tell us your browser and device (mobile/desktop).

## Requesting features

Open an issue with the **Feature request** template and describe:

- The problem you're trying to solve.
- How you'd expect the feature to work.
- Why it matters to you.

## Contact

- **Feedback & bugs:** use the app's contact form
  (https://openlysts.dpdns.org/contact)
- **Security:** see [SECURITY.md](SECURITY.md)
- **Licensing / partnerships / running Openlysts privately:**
  openlysts@gmail.com — we're open to talking about licensed
  deployments for businesses that need their own instance.

## Code of Conduct

We expect everyone participating in discussions to be respectful and
constructive. Be kind — this project is run by one person with a lot
of love and very little sleep.

Thank you for being part of Openlysts. ❤️
